# Clay Waterson — Sharable

Public, intentionally sanitized artifacts for events, social distribution, demonstrations, and external review.

## Purpose

This repository is the public distribution shelf for Clay Waterson proof objects. It contains material that has been explicitly prepared for sharing. Absence from this repository should not be interpreted as permission to publish material from other Clay Waterson systems or repositories.

## Structure

- `demos/` — interactive and documented proof objects.
- `events/` — event-ready handoffs and supporting material.
- `social/` — public social-media assets and supporting proof.
- `frameworks/` — intentionally released framework summaries or public-safe references.
- `media/` — approved visual/media assets when required.

## Public boundary

Do not place the following here:

- client-identifying or confidential material;
- credentials, secrets, tokens, or private configuration;
- private commercial implementation logic;
- unreviewed third-party material or unclear provenance;
- internal orchestration instructions unless intentionally released.

Every substantial artifact should state its maturity, version, provenance, and license.
